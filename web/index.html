How the list is set

Fields are read the way people write them. “AI”, “Artificial Intelligence” and a misspelt “Machine learnig” all find the right lecturer. A lecturer can list several specializations separated by commas.

The whole list is solved at once. Every student goes to the closest-matching lecturer that still has room, and loads stay as even as the limits allow. Nobody is placed first-come, first-served.

You have the last word. Weak matches are circled in blue biro. Click any name to move that student; the list, the counts and every export follow. Your files never leave this computer: everything runs in your browser.
